# Student CRUD Application

## Project Information

- University: Vistula University
- Project: Java CRUD Application
- Group: 3
- Programming Language: Java 21

## Project Description

This project is a web-based Student Management System developed using Java and Spring Boot.

The application allows users to manage student records through a simple and user-friendly interface.

## Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- Vaadin
- H2 Database
- Maven
- Git & GitHub

## Features

The application supports four main CRUD operations:

- **Create** — Add new students to the database.
- **Read** — View all registered students.
- **Update** — Edit existing student information.
- **Delete** — Remove students from the database.

## Student Information

Each student record contains:

- Student ID
- Full Name
- Email Address
- Course

## Database

The application uses an H2 database to store student information.

Spring Data JPA is used to perform database operations.

## Project Structure

- `Student.java` — Student entity.
- `StudentRepository.java` — Database operations.
- `MainView.java` — User interface and CRUD functionality.
- `StudentcrudApplication.java` — Main application entry point.
